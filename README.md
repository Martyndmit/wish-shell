# wish — простий Unix-шелл

Реалізація проєкту
[processes-shell](https://github.com/remzi-arpacidusseau/ostep-projects/blob/master/processes-shell/README.md)
з курсу OSTEP мовою C.

## Збірка

```sh
make
```

## Запуск

```sh
./wish
```

## Тести

```sh
make test
```

Скрипт `scripts/run-tests.sh` завантажує офіційні тести OSTEP у
`.ostep-projects/` і запускає їх для `./wish`.
